# Homebrew tap for Lumen Presenter

```sh
brew install --cask gowthamrajum/lumen/lumen-presenter
```

Installs the latest [Lumen Presenter](https://github.com/gowthamrajum/lumen-presenter)
and clears the quarantine so it opens without a Gatekeeper prompt (the build is
unsigned / open-source). Update with `brew upgrade --cask lumen-presenter`.
